# SEMMA — Heart Disease Prediction (UCI Cleveland)

Full SEMMA (Sample, Explore, Modify, Model, Assess) project on the UCI Heart Disease dataset — Cleveland processed set, 303 rows × 14 attributes. Built for the CMPE 256 Data Mining Methodologies assignment.

> ⚠️ **This is a teaching demonstration of the SEMMA methodology, NOT a diagnostic tool.** It must never be used to diagnose or triage any person. Data are from a single clinic in the 1980s; n = 303.

## Results (held-out test set, n = 61, seed 42)

| Model | Test ROC-AUC | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|---|
| Logistic Regression | 0.9600 | 0.8525 | 0.7879 | 0.9286 | 0.8525 |
| Random Forest (tuned) | 0.9610 | 0.9180 | 0.8710 | 0.9643 | 0.9153 |
| HistGradientBoosting | 0.9632 | 0.9180 | 0.8710 | 0.9643 | 0.9153 |

The top two models are a statistical tie (0.002 AUC on 61 patients is noise) and make identical test errors. **Recommended prototype: tuned Random Forest** (joint-best F1/recall, plus direct feature importances); HistGradientBoosting is the challenger. Dataset disease prevalence: 45.87% (139/303).

## Reproduce

1. Download: the notebook fetches `https://archive.ics.uci.edu/ml/machine-learning-databases/heart-disease/processed.cleveland.data` into `data/` (already included here).
2. Target is binarized: raw `target` 0 = no disease, 1–4 = disease present → 0/1.
3. Stratified 80/20 train/test split (seed 42) + 5-fold stratified CV.
4. All metrics in `report.md` and `medium-article.md` match the executed notebook output exactly.

## Methodology note

SEMMA originated in SAS Enterprise Miner. No SAS licence was available for this project, so each SEMMA step is implemented in Python with its SAS-equivalent node named (Sample = Data Partition, Explore = StatExplore/Graph Explore, Modify = Impute/Transform/Variable Selection, Model = Regression/Decision Tree/Gradient Boosting, Assess = Model Comparison/ROC). The logic — not the vendor tool — is what is being demonstrated.
